# 🥑 NutriFlow · Plan Alimenticio Interactivo

Interfaz web moderna, dinámica y gamificada para seguir el plan nutricional personalizado (Plan A · 18 de Noviembre y Plan B · 19 de Noviembre), con calendario configurable, recetario paso a paso y lista inteligente de compras.

## 🌐 Demo en vivo
👉 **[Abrir NutriFlow](https://destroycrons.github.io/nutriflow-dieta/)**

## ✨ Funcionalidades
- **⚡ Mi Rutina Hoy:** línea de tiempo interactiva con seguimiento de comidas, anillo de progreso, puntos XP, celebración con confeti al completar el día y registro de hidratación.
- **📅 Calendario Personalizado:** selecciona tus días de entrenamiento (Plan B) y horarios de desayuno/entreno para recalcular automáticamente toda tu rutina, personalizar días libres y exportar tu semana a Google Calendar / Apple Calendar (`.ics`).
- **👨‍🍳 Recetario & Modo Cocina:** las 15 preparaciones del plan con porciones exactas, escalador (`×1`, `×2`, `×3`), checklist de ingredientes, pasos guiados y temporizador de cocina integrado con alerta sonora.
- **🛒 Súper & Meal Prep:** lista de compras semanal calculada automáticamente por pasillos del supermercado + guía rápida de *meal prep*.
- **🌙 / ☀️ Modo Oscuro y Claro:** diseño responsivo para móvil y escritorio con persistencia local (`localStorage`).
